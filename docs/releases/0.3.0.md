# FerrisSearch 0.3.0

Release branch: `release/0.3.0`

Comparison base: `v0.2.0..164882b`

This release covers 86 commits across 530 files, with 281,563 insertions and 21,851 deletions compared to `v0.2.0`.

## Highlights

- FerrisSearch 0.3.0 completes all 50 engineering work packages (`FS-001` through `FS-050`) across Roadmap Gates 0 through 4, converging mutable local shards and immutable object-store splits into one unified lifecycle backed by formal TLA+ verification, deterministic fault injection, bounded resource governance, and reproducible research evidence.

## Major Changes

- **Write authority, optimistic concurrency, and streaming bulk (`FS-001`, `FS-009`–`FS-014`):** Single and bulk writes carry authoritative WAL v3 `_seq_no`, `_primary_term`, and `_version` receipts, enforce `if_seq_no`/`if_primary_term` preconditions and primary-side CAS `_update`, deduplicate retries via WAL-persisted `operation_id` ledgers, certify `minimum_durable_copies` with conditional Raft replica exclusion, and stream multi-gigabyte NDJSON `_bulk` payloads through checksummed disk staging within bounded memory.
- **Fenced manifest publication and snapshot-safe object-store GC (`FS-002`, `FS-015`–`FS-021`, `FS-039`–`FS-041`):** `StorageManager` enforces MAC-authenticated `CompareToken` compare-and-swap on local filesystems (`flock` + two-slot revision state) and S3-compatible stores (`If-None-Match` / `If-Match`). Raft manages one `ManifestWriterAuthority` lease and monotonic `writer_epoch` per index so parallel producers stage splits while a single fenced sequencer commits v3 manifests, acyclic compaction lineage (`/_remote_store/compact`), reachability inventories (`/_remote_store/inventory`), and snapshot-lease-pinned mark-and-sweep GC (`/_remote_store/janitor`).
- **Staged snapshot bootstrap, explicit ISR state machine, and complete vector recovery (`FS-022`–`FS-027`):** Flushed shards persist checksum-verified `ShardSnapshotManifest` snapshots. Peer recovery stages incoming snapshots into `<shard_dir>.staging` with crash-safe `<shard_dir>.backup` rollback, streams bounded gap-free WAL suffix chunks under `ReplicaCopyState`, applies reactive `ReplicaPolicySettings` on followers without request ingress, and restores or stream-rebuilds complete USearch vector indexes.
- **Unified tiered hot-delta and immutable-split lifecycle (`FS-003`–`FS-004`, `FS-034`–`FS-038`, `FS-042`–`FS-043`):** Tiered indices (`lifecycle_mode: "tiered"`) ingest into replicated hot-delta shards, seal contiguous sequence ranges into immutable splits (`/_remote_store/seal`), commit `ShardPublishedWatermark` boundaries, and resolve one pinned `ReadSnapshot` across hot delta and splits with versioned tombstones. Cluster backup/verify/restore (`/_snapshot/{snapshot_id}*`), manifest repair (`/_remote_store/repair`), and online `local_shards` -> `tiered` migration and rollback (`/_lifecycle/{migrate,rollback,status}`) preserve exact oracle equivalence.
- **Scale scheduling, streaming hydration, mixed schema generations, and multi-tenant isolation (`FS-005`, `FS-028`–`FS-033`, `FS-044`–`FS-050`):** Request-scoped cancellation, monotonic gRPC deadlines, per-class `AdmissionController` queues, `ResourceGovernor` byte pools, 64 KiB streaming bundle hydration, and the unified node cache governor (`/_nodes/cache/inventory`) bound memory and disk usage. Query roots use TTL-bounded leaf capability inventories and $O(S \cdot L)$ top-$K$ rendezvous scheduling with deduplicated retry (`assignment_id`). Additive schema evolution (`GET/PUT/POST /{index}/_mapping`) executes safely across mixed split schema generations, and Raft-replicated tenant quotas (`/_security/quota*`) plus redacted audit logs (`/_security/audit`) isolate multi-tenant workloads.

## Notable User-Facing Outcomes

- Existing `local_shards` indices can migrate online to `tiered` object-store lifecycle mode (`POST /{index}/_lifecycle/migrate`) and roll back without losing document versions or search equivalence.
- Additive fields added via `PUT /{index}/_mapping` are immediately queryable across older local segments and remote splits as typed `NULL`s across both Query DSL (`exists`, aggregations, sort) and SQL, and older splits upgrade automatically on compaction.
- Operators can enforce per-principal and per-index concurrency and byte budgets (`PUT /_security/quota/{scope}/{id}`), inspect unified node cache usage (`GET /_nodes/cache/inventory`), and audit security events with automatic secret redaction (`GET /_security/audit`).
